ray_path_observer_agenda
========================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.ray_path_observer_agenda
   :type: ~pyarts3.arts.Agenda

   Gets the propagation path as it is observed.

   The intent of this agenda is to provide a propagation path as seen from the observer
   position and line of sight.

   .. tip::
       The perhaps easiest way to set this agenda up is to use the :func:`~pyarts3.Workspace.ray_path_observer_agendaSetGeometric` method.

   .. rubric:: Execution and customization

   See :func:`~pyarts3.Workspace.ray_path_observer_agendaSet` for builtin options that selects execution options.

   You can execute :attr:`~pyarts3.Workspace.ray_path_observer_agenda` directly from the workspace by calling :func:`~pyarts3.Workspace.ray_path_observer_agendaExecute`.

   As all agendas in ARTS, it is also customizable via its operator helper class: :class:`~pyarts3.arts.ray_path_observer_agendaOperator`.
   See it, :func:`~pyarts3.Workspace.ray_path_observer_agendaSetOperator`, and :func:`~pyarts3.Workspace.ray_path_observer_agendaExecuteOperator` for more details.

   Also see the :class:`~pyarts3.arts_agenda` property for how to fully define an agenda in python.

   .. rubric:: Default value

   #. Shares the global :attr:`~pyarts3.Workspace.atm_field`
   #. Shares the global :attr:`~pyarts3.Workspace.max_stepsize`
   #. Shares the global :attr:`~pyarts3.Workspace.surf_field`
   #. as_sensor = 1
   #. :func:`~pyarts3.Workspace.ray_pathInit`, using: pos = :attr:`~pyarts3.Workspace.obs_pos`, los = :attr:`~pyarts3.Workspace.obs_los`
   #. surf_search_accuracy = 0.1
   #. surf_safe_search = 1
   #. :func:`~pyarts3.Workspace.ray_pathSetGeometricExtremes`
   #. :func:`~pyarts3.Workspace.ray_pathFillGeometricStepwise`
