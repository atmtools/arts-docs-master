spectral_tramat_path
====================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.spectral_tramat_path
   :type: ~pyarts3.arts.TransmittanceMatrix

   Transmission matrices and derivatives along the propagation path.

   The inner dimensions depends on :attr:`~pyarts3.Workspace.rte_option` and :attr:`~pyarts3.Workspace.jac_targets`.

   The object should have these sizes internally:
   - Transmission matrices: :attr:`~pyarts3.Workspace.freq_grid` x :attr:`~pyarts3.Workspace.ray_path`
   - Jacobian matrices: :attr:`~pyarts3.Workspace.freq_grid` x :attr:`~pyarts3.Workspace.ray_path` x :attr:`~pyarts3.Workspace.jac_targets` (target count)
   - Linear evolution operators: :attr:`~pyarts3.Workspace.freq_grid` x :attr:`~pyarts3.Workspace.ray_path` (if :attr:`~pyarts3.Workspace.rte_option` requires it)
   - Linear evolution operator Jacobians: :attr:`~pyarts3.Workspace.freq_grid` x :attr:`~pyarts3.Workspace.ray_path` x :attr:`~pyarts3.Workspace.jac_targets` (target count - if :attr:`~pyarts3.Workspace.rte_option` requires it)
   - Cumulated transmission matrices: :attr:`~pyarts3.Workspace.freq_grid` x :attr:`~pyarts3.Workspace.ray_path` (if :attr:`~pyarts3.Workspace.jac_targets` has any elements)
