inversion_iterate_agenda
========================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.inversion_iterate_agenda
   :type: ~pyarts3.arts.Agenda

   Work in progress ...

   See :func:`~pyarts3.Workspace.OEM`.

   .. note::
       The output :attr:`~pyarts3.Workspace.measurement_jac` size may depend on the :attr:`~pyarts3.Workspace.do_jac` input.

   .. rubric:: Execution and customization

   See :func:`~pyarts3.Workspace.inversion_iterate_agendaSet` for builtin options that selects execution options.

   You can execute :attr:`~pyarts3.Workspace.inversion_iterate_agenda` directly from the workspace by calling :func:`~pyarts3.Workspace.inversion_iterate_agendaExecute`.

   As all agendas in ARTS, it is also customizable via its operator helper class: :class:`~pyarts3.arts.inversion_iterate_agendaOperator`.
   See it, :func:`~pyarts3.Workspace.inversion_iterate_agendaSetOperator`, and :func:`~pyarts3.Workspace.inversion_iterate_agendaExecuteOperator` for more details.

   Also see the :class:`~pyarts3.arts_agenda` property for how to fully define an agenda in python.

   .. rubric:: Constraints

   #. On output, the measurement vector and Jacobian must match expected size.
   #. On output, the model state vector and Jacobian must match expected size.
