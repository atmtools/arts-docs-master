select_species
==============

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.select_species
   :type: ~pyarts3.arts.SpeciesEnum

   Species selection.

   When Bath is selected, all species are used.  Otherwise, this variable should control so that only the selected species is used.



   .. rubric:: Default value

   ``AIR``
