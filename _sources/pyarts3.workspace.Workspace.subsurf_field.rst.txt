subsurf_field
=============

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.subsurf_field
   :type: ~pyarts3.arts.SubsurfaceField

   The sub-surface field.

   This contains global subsurface properties, such as temperature.
   It also contains many properties that are used by specific
   subsurface-related methods.

   It is a 3D field with :attr:`~pyarts3.workspace.Workspace.alt`, :attr:`~pyarts3.workspace.Workspace.lat`, and :attr:`~pyarts3.workspace.Workspace.lon` dimensions.

   For more information, see :doc:`user.subsurf_field`.



   .. rubric:: Default value

   ``"bottom_depth": 1.7976931348623157e+308``
