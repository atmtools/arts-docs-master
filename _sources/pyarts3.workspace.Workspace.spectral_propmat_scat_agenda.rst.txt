spectral_propmat_scat_agenda
============================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.spectral_propmat_scat_agenda
   :type: ~pyarts3.arts.Agenda

   Computes the part of the propagation matrix that relates to scattering.

   .. rubric:: Execution and customization

   See :func:`~pyarts3.workspace.Workspace.spectral_propmat_scat_agendaSet` for builtin options that selects execution options.

   You can execute :attr:`~pyarts3.workspace.Workspace.spectral_propmat_scat_agenda` directly from the workspace by calling :func:`~pyarts3.workspace.Workspace.spectral_propmat_scat_agendaExecute`.

   As all agendas in ARTS, it is also customizable via its operator helper class: :class:`~pyarts3.arts.spectral_propmat_scat_agendaOperator`.
   See it, :func:`~pyarts3.workspace.Workspace.spectral_propmat_scat_agendaSetOperator`, and :func:`~pyarts3.workspace.Workspace.spectral_propmat_scat_agendaExecuteOperator` for more details.

   Also see the :class:`~pyarts3.workspace.arts_agenda` property for how to fully define an agenda in python.

   .. rubric:: Constraint

   #. On output, :attr:`~pyarts3.workspace.Workspace.spectral_propmat_scat` has the size of :attr:`~pyarts3.workspace.Workspace.freq_grid`.
