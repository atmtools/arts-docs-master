absorption_predefined_model_data
================================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.absorption_predefined_model_data
   :type: ~pyarts3.arts.PredefinedModelData

   Can currently only contain data for new MT CKD models of water.

   See :doc:`concept.absorption.predef` for more information on predefined model calculations.
