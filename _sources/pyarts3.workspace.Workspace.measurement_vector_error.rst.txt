measurement_vector_error
========================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.measurement_vector_error
   :type: ~pyarts3.arts.Vector
   
   The model measurment vector error for, e.g., a sensor.
   
   This must often be the same size as :attr:`~pyarts3.workspace.Workspace.measurement_sensor`.
   
   See :attr:`~pyarts3.workspace.Workspace.measurement_vector` for more details.
   In that notation, this is :math:`\vec{y}_\epsilon`.
