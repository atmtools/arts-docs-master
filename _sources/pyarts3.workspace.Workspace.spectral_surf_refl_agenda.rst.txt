spectral_surf_refl_agenda
=========================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.spectral_surf_refl_agenda
   :type: ~pyarts3.arts.Agenda

   An agenda to compute the surface reflectance.

   .. rubric:: Execution and customization

   See :func:`~pyarts3.workspace.Workspace.spectral_surf_refl_agendaSet` for builtin options that selects execution options.

   You can execute :attr:`~pyarts3.workspace.Workspace.spectral_surf_refl_agenda` directly from the workspace by calling :func:`~pyarts3.workspace.Workspace.spectral_surf_refl_agendaExecute`.

   As all agendas in ARTS, it is also customizable via its operator helper class: :class:`~pyarts3.arts.spectral_surf_refl_agendaOperator`.
   See it, :func:`~pyarts3.workspace.Workspace.spectral_surf_refl_agendaSetOperator`, and :func:`~pyarts3.workspace.Workspace.spectral_surf_refl_agendaExecuteOperator` for more details.

   Also see the :class:`~pyarts3.workspace.arts_agenda` property for how to fully define an agenda in python.

   .. rubric:: Constraints

   #. :attr:`~pyarts3.workspace.Workspace.spectral_surf_refl` match :attr:`~pyarts3.workspace.Workspace.freq_grid` size
   #. :attr:`~pyarts3.workspace.Workspace.spectral_surf_refl_jac` match :attr:`~pyarts3.workspace.Workspace.jac_targets` target count and :attr:`~pyarts3.workspace.Workspace.freq_grid` size
