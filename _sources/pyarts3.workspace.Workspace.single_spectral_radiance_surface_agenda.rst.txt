single_spectral_radiance_surface_agenda
=======================================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.single_spectral_radiance_surface_agenda
   :type: ~pyarts3.arts.Agenda

   Gets spectral radiance as seen of the surface for a single frequency.

   Otherwise same as :attr:`~pyarts3.workspace.Workspace.spectral_radiance_surface_agenda`.

   .. rubric:: Execution and customization

   See :func:`~pyarts3.workspace.Workspace.single_spectral_radiance_surface_agendaSet` for builtin options that selects execution options.

   You can execute :attr:`~pyarts3.workspace.Workspace.single_spectral_radiance_surface_agenda` directly from the workspace by calling :func:`~pyarts3.workspace.Workspace.single_spectral_radiance_surface_agendaExecute`.

   As all agendas in ARTS, it is also customizable via its operator helper class: :class:`~pyarts3.arts.single_spectral_radiance_surface_agendaOperator`.
   See it, :func:`~pyarts3.workspace.Workspace.single_spectral_radiance_surface_agendaSetOperator`, and :func:`~pyarts3.workspace.Workspace.single_spectral_radiance_surface_agendaExecuteOperator` for more details.

   Also see the :class:`~pyarts3.workspace.arts_agenda` property for how to fully define an agenda in python.
