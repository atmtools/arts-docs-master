.. automodule:: pyarts3.arts.sensor


.. rubric:: Classes


.. list-table::

  * - :class:`~pyarts3.arts.sensor.AntennaPattern`
    - Base class for angular antenna responses defined around a bore line of sight.
  * - :class:`~pyarts3.arts.sensor.AntennaPatternField`
    - A 2D gridded antenna response on local zenith and azimuth offsets.
  * - :class:`~pyarts3.arts.sensor.BoxChannel`
    - A channel with uniform weights across a finite relative-frequency interval.
  * - :class:`~pyarts3.arts.sensor.Builder`
    - Combines channels and an antenna pattern into sensor obsels for paired position/LOS samples.
  * - :class:`~pyarts3.arts.sensor.Channel`
    - Base class for relative spectrometer channel responses.
  * - :class:`~pyarts3.arts.sensor.DiracChannel`
    - A single-frequency relative channel.
  * - :class:`~pyarts3.arts.sensor.GaussianAiryAntenna`
    - A Gaussianized Airy antenna whose width scales with wavelength and aperture diameter.
  * - :class:`~pyarts3.arts.sensor.GaussianAntenna`
    - A Gaussian antenna response defined by angular offset from the bore LOS on a local zenith/azimuth grid.
  * - :class:`~pyarts3.arts.sensor.GaussianChannel`
    - A Gaussian relative channel response.
  * - :class:`~pyarts3.arts.sensor.GriddedAntennaPattern`
    - A gridded angular antenna response on local zenith and azimuth offsets.
  * - :class:`~pyarts3.arts.sensor.HeterodyneFrequencyRange`
    - A staged heterodyne mixer and filter response builder.
  * - :class:`~pyarts3.arts.sensor.PencilBeamAntenna`
    - A 1x1 antenna response centered on the bore line of sight.
  * - :class:`~pyarts3.arts.sensor.Spectrometer`
    - A spectrometer made from channels arranged on one shared relative-frequency grid.
