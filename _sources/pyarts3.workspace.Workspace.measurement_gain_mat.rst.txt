measurement_gain_mat
====================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.measurement_gain_mat
   :type: ~pyarts3.arts.Matrix

   Contribution function (or gain) matrix.

   This matrix is the partial derivative of the retrieved state vector with respect to the :attr:`~pyarts3.workspace.Workspace.measurement_vec`.

   Usage: Used and set by inversion methods.
