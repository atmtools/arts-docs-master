spectral_propmat_and_atm_path_agenda
====================================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.spectral_propmat_and_atm_path_agenda
   :type: ~pyarts3.arts.Agenda

   Computes several path parameters along the path.

   The main use of this agenda is to allow adapting the path points
   based on spectral parameters.

   .. rubric:: Execution and customization

   See :func:`~pyarts3.workspace.Workspace.spectral_propmat_and_atm_path_agendaSet` for builtin options that selects execution options.

   You can execute :attr:`~pyarts3.workspace.Workspace.spectral_propmat_and_atm_path_agenda` directly from the workspace by calling :func:`~pyarts3.workspace.Workspace.spectral_propmat_and_atm_path_agendaExecute`.

   As all agendas in ARTS, it is also customizable via its operator helper class: :class:`~pyarts3.arts.spectral_propmat_and_atm_path_agendaOperator`.
   See it, :func:`~pyarts3.workspace.Workspace.spectral_propmat_and_atm_path_agendaSetOperator`, and :func:`~pyarts3.workspace.Workspace.spectral_propmat_and_atm_path_agendaExecuteOperator` for more details.

   Also see the :class:`~pyarts3.workspace.arts_agenda` property for how to fully define an agenda in python.

   .. rubric:: Constraint

   #. On output, all path arrays have the same size.
