model_state_vec_apriori
=======================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.model_state_vec_apriori
   :type: ~pyarts3.arts.Vector

   An apriori state vector of the model.

   See :attr:`~pyarts3.workspace.Workspace.model_state_vec` for more details.
   This is the state vector that is assumed to be the a priori state of the model.
   In normal circumstances, this is the state vector that is used to
   start the inversion process.  In :func:`~pyarts3.workspace.Workspace.OEM`, this is :math:`\vec{x}_a`.
