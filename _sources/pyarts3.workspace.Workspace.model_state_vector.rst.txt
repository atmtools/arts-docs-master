model_state_vector
==================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.model_state_vector
   :type: ~pyarts3.arts.Vector
   
   A state vector of the model.
   
   This represents the :emphasis:`chosen` state of the model.
   In the notation of :attr:`~pyarts3.workspace.Workspace.measurement_vector` and :func:`~pyarts3.workspace.Workspace.OEM`,
   :math:`\vec{x}` is the :attr:`~pyarts3.workspace.Workspace.model_state_vector`.
   
   To choose the state of the model, you must setup :attr:`~pyarts3.workspace.Workspace.jacobian_targets` to
   include the state parameters you want to be able to change.
   
   
   
   .. rubric:: Default value
   
   ``[]``
