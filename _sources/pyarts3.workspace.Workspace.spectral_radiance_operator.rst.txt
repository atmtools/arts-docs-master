spectral_radiance_operator
==========================

.. currentmodule:: pyarts3.workspace

.. attribute:: Workspace.spectral_radiance_operator
   :type: ~pyarts3.arts.SpectralRadianceOperator

   The spectral radiance operator.

   This is a class that can compute the spectral radiance
   along a path for a single viewing direction and frequency.

   It provides several methods to get the path of the spectral
   radiance.
